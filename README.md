# Simplotel Hospitality Frontend 🌐✨

A responsive **front-end web page** designed for **Simplotel** to showcase hospitality services with a modern, user-friendly, and visually appealing interface.  
Built using **HTML, CSS, and JavaScript**, the page ensures smooth navigation and a seamless browsing experience across devices.

---

## 🚀 Features
- 📱 **Responsive Design** – Works across desktop, tablet, and mobile devices  
- 🎨 **Modern UI/UX** – Attractive layouts with hospitality-focused design  
- 🖼️ **Service Showcase** – Sections for hospitality offerings  
- 🖱️ **Easy Navigation** – Simple and intuitive interface
